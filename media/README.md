# 媒体资源放置说明

把首页所需资源放在这个目录中，页面内使用 `/media/文件名` 引用。

- `hero.webp`：首页头图，建议 2400 × 1350，WebP/JPG
- `hero-morning.webp`、`hero-noon.webp`、`hero-evening.webp`、`hero-night.webp`：四时段头图
- `hero-loop.webm`：可选的首页循环视频，建议无声 WebM
- `avatar.png`：个人头像
- `gallery/`：画廊原图
- `music/`：音乐文件与封面

当前雏形的头图使用纯 CSS 绘制，所以即使没有上述图片也能完整预览。
