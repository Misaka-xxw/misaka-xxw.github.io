# 碎碎念
《某科学的超电磁炮》是**梦**开始的地方。我很想搓个网站，以《魔法禁书目录》及其衍生作作为主题。然后，Codex太好用了你知道吗（电脑里有三C大作——Copilot、Claude Code和Codex），所以崭新的个人主页诞生啦！

这个主页会根据北京时间，在黎明、正午、黄昏与午夜之间变化（脑叶公司考验打多了）。这是当年玩网易的魔法禁书目录手游时很喜欢的创意。然而，高考未至，昔游已逝。2022年，这个命苦的游戏已关服，唉。。。

2026年7月，我从b站上找到了该动态背景的资源，做成了webm格式，制作这个网站。当我用Adobe illustrator做出一个挺逼真的按钮（首页的“建立连接”），我还挺开心的说。

好像是8月份，电击文库零境交错、魔法禁书目录幻想收束手游、网易魔法禁书目录手游三款魔禁相关游戏的复活，接踵而至，令人感慨，科技发展也挺好的。

扯远了（生掰回去）。。。说回网站，颜色搭配是用颜色提取器提取背景中的主要颜色，我再选择和调整的，应该还算比较和谐吧。博客也沿用了和主题的相同的四套颜色，但去掉了动态视频，让阅读区域更安静一些。至于性能优化，AI加油喵。

其实之前已经有[别的博客](https://misaka-xxw.github.io/blog/)了，是大佬力荐的框架和主题。不过那个博客画风比较正经，我还需要一个能放飞自我的网站。这个（网站），那个（网站），不都是我的吗？这俩我都更新，不咕咕咕的话。

应该没人看这两个博客。一个给自己留下笔记，一个给自己留下回忆吧。
